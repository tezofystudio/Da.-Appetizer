# Da. Appetizer — ইমার্সিভ মেনু প্রিভিউ

মূল সাইট (tezofystudio.github.io/Da.-Appetizer) অপরিবর্তিত রেখে, মেনু ক্যাটাগরির আইটেমগুলোর জন্য ফুল-স্ক্রিন 3D-স্টাইল প্রিভিউ যোগ করা হয়েছে।

## যা যোগ হয়েছে
- মূল মেনুর যেকোনো ক্যাটাগরি চাপলে সরাসরি সেই ক্যাটাগরির খাবারের ফুল-স্ক্রিন প্রিভিউ খোলে (কার্ড থেকে খাবার উড়ে আসে)।
- প্রিভিউতে: খাবারের ওপরে ক্যাটাগরির নাম, খাবারের ঠিক নিচে খাবারের নাম, নিচে বামে স্বচ্ছ দাম, নিচে ডানে অর্ডার কার্ট আইকন, আর একদম নিচে সাইটের মূল নেভিগেশন।
- নিচ থেকে ওপরে স্ক্রল/সোয়াইপ করলে দাম-সাইজ-এক্সট্রা-পরিমাণের মেনু উঠে আসে (মূল নেভিগেশন সরে যায়); ওপর থেকে নিচে স্ক্রল করলে মেনু নেমে যায় ও নেভিগেশন ফিরে আসে। মাউস হুইল, "বিস্তারিত" বাটন, ↑/↓ কী এবং Esc-ও কাজ করে।
- ওপরে ডানে ক্যাটাগরি আইকন: চাপলে ১১টি ক্যাটাগরির তালিকা খোলে; যেকোনোটিতে চাপলে সেই ক্যাটাগরির খাবার প্রিভিউতে আসে।
- কার্ট আইকনে চাপলে খাবার ছোট হয়ে ওপরে ভাসে, নিচ থেকে অর্ডারের বিস্তারিত ওঠে। ⌄ বাটন, ভাসমান খাবারে ট্যাপ বা শিট নিচে টানলে প্রিভিউতে ফেরে।
- সব খাবার একটি 360° রিং-এ সাজানো; দ্রুত ডানে-বামে সোয়াইপ, পাশের তীর বা খাবারের নামের নিচের ছবির স্লাইডার দিয়ে বদলায়। ধীরে আঙুল টানলে খাবার টিল্ট হয়।
- ক্যাটাগরির নামের উপরে সব খাবারের ছোট আইকন + নামের একটি টিকার এলোমেলো ক্রমে অবিরাম চলে; যেকোনো নামে ট্যাপ করলে সেই খাবার আসে (হোভার/ফোকাসে থামে, reduced-motion-এ হাতে স্ক্রল হয়)।
- প্রিভিউ খোলার বা স্পর্শের ২ সেকেন্ড পর নিচের নেভিগেশন বার লুকিয়ে যায়; আবার স্পর্শ করলে ফিরে আসে। নেভ লুকানো থাকলে দাম ও অর্ডার-কার্ট বাটন নেমে এসে নেভের জায়গা নেয়; নেভ দেখা গেলে কার্ট বাটনের জায়গায় ক্যাটাগরি মেনু বাটন আসে (তালিকা নিচ থেকে খোলে)। ক্যাটাগরি তালিকা, ডিটেইলস বা কার্ট খোলা থাকলে টাইমার থেমে থাকে।
- সাইটের বাংলা/EN ও লাইট/ডার্ক মোড প্রিভিউতেও কাজ করে।

## গুরুত্বপূর্ণ
সাইটের পাবলিক সোর্সে আইটেম-ভিত্তিক নাম/দাম নেই, তাই প্রতিটি ক্যাটাগরিতে একটি **নমুনা খাবার ও ডেমো দাম** দেওয়া আছে (AI-তৈরি ছবি)। আসল মেনু দিলে `data.js`-এর `dishes` তালিকায় বসালেই হবে। অর্ডার শুধু এই ডিভাইসে ডেমো হিসেবে সেভ হয় — রেস্তোরাঁয় পাঠানো হয় না, কোনো পেমেন্ট নেই।

## চালানো
```
npm install
npm run dev      # http://localhost:3000
npm run build    # dist/ → GitHub Pages-এ আপলোড করা যায় (relative path)
python export_demo.py   # এক ফাইলের অফলাইন HTML
```
